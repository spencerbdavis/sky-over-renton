Top-down aircraft outlines by ICAO type code from RexKramer1/AircraftShapesSVG
(https://github.com/RexKramer1/AircraftShapesSVG), copied from the phomemo wall
project. tools/build_shapes.py turns them into the small filled, cropped shapes
in web/shapes/ (+ index.json with each type's real size and the alias table).
